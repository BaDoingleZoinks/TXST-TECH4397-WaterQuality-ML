# Notebooks

Python notebooks used throughout the Fall 2026 semester in TECH 4397, exploring chemical classification, dose estimation, dissolved-oxygen drift, water-matrix effects, and contaminant mixtures.

Some notebooks generate synthetic sensor data or simulated disturbances rather than loading the original experimental measurements. Check each notebook’s data-generation and loading steps before interpreting its results.

Run cells in order using **Jupyter** or **Google Colab**, with the required dependencies installed. Update data paths to reference the `data/` folder where applicable.

These notebooks document instructional analyses and computational demonstrations. Results require review for validation limitations and known implementation errors before reuse or field-deployment claims.
